# WEEK 0 – Systems and Concurrency Fundamentals

## Overview

This week focuses on understanding modern CPU
architecture, instruction reordering, concurrent
programming, and memory synchronization mechanisms.

## First Task

### Instruction Reordering & Memory Barriers

Why do compilers and out-of-order CPU pipelines
reorder instructions, causing concurrency bugs
that slip past unit tests?

At the hardware level, how do memory fences
(acquire-release vs. sequential consistency)
affect CPU store buffers and invalidate queues?

## Topics Covered

1. Instruction Reordering
2. Compiler Optimization
3. Out-of-Order CPU Execution
4. Data Races and Race Conditions
5. Limitations of Unit Testing
6. CPU Store Buffers
7. Invalidate Queues
8. MESI Protocol and Cache Coherence
9. Memory Barriers and Fences
10. Acquire-Release Memory Ordering
11. Sequential Consistency
12. Hardware-Level Memory Synchronization

## Study Material

Detailed technical notes covering theoretical
concepts, hardware architecture, flowcharts,
C++ examples, and industry-relevant applications.


## Learning Outcomes

- Understand compiler and CPU instruction reordering.
- Understand concurrency and data race problems.
- Explore hardware-level memory synchronization.
- Differentiate acquire-release and sequential consistency.
- Understand cache coherence and memory barriers.
- Develop industry-relevant concurrent programming skills.
